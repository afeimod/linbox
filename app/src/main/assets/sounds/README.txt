# 启动音效目录

此目录用于存放各 Windows 主题的启动音效 mp3 文件：

- win95.mp3   - Windows 95 启动音效
- winxp.mp3   - Windows XP 启动音效
- win7.mp3    - Windows 7 启动音效
- win10.mp3   - Windows 10 启动音效
- win11.mp3   - Windows 11 启动音效

由于版权原因，本项目不附带微软原始音效文件。
应用在 assets 缺失时会静默跳过，不影响功能。

如需启用启动音效，请自行将合法获取的 mp3 文件放入此目录，
文件名必须与上述完全一致。
