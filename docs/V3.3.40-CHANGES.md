**代码**
- `launcher/FexConfSupport.kt`（新）：变量定义表 / 四档预设解析（org.json，零新依赖）+ 当前生效值读写（`fex_active.conf`）。
- `ContainerScreens.kt`：高级页新增 **「🧬 FEX配置」页（放在「⚡ DY配置」旁边）**——四档预设一键装载 + 15 变量逐行编辑（0/1 勾选 / 多值下拉 / 数字编辑框）+「应用配置」整写 fex_active.conf +「重置默认」。UI 交互与 wineguanli DY 页 / WinFusion FEXPresetEditDialogFragment 同款。

**生效链路（与 DY 配置完全同构）**：`fex_active.conf` 落 App 内部 conf 目录 → 启动链 `applyOptConfEnv` source 全部 *.conf 时自动 export → wine 子进程经 ProcessBuilder 环境继承。优先级：容器 env= > FEX 配置页 > 容器预设档 > 变量默认值。

## 2. 注册表 JSON 打入（替代 .reg + regedit 方式）

**新增 `launcher/JsonRegistry.kt`（新引擎）**——JSON 描述 → 直接文本合并进前缀 `user.reg / system.reg / userdef.reg`（wine "WINE REGISTRY Version 2" 保存格式逐字节同构：段头 / 值行 / hex 多行续行整跨度替换 / `\xHH` 转义）：

```json
[
  {"hive": "HKCU", "key": "Software\\Wine\\DllOverrides",
   "values": [
     {"name": "d3d9", "type": "sz", "data": "native,builtin"},
     {"name": "LogPixels", "type": "dword", "data": 96},
     {"name": "Old", "type": "delete"}
   ]},
  {"hive": "HKLM", "key": "...", "delete": true}
]
```

支持类型：sz / expand_sz / multi_sz / dword / qword / binary / none / delete（值）/ delete（整段）。hive：HKCU / HKLM / HKCR（→Software\Classes）/ HKU\.Default。写入前自动收尾存活 wineserver（`WineServerUtils.isServerRunning` 新增快查）——防内存注册表缓存回写覆盖直写。

**改造的调用点（全部去 regedit 进程拉起）**：
| 位置 | 旧链路 | 新链路 |
|---|---|---|
| `WineRegistry.ensureEmulateModeset` | `wine reg add`（1~3s/次） | JSON 直写 |
| `WineRegistry.setVirtualDesktopRegistry` | 2×`wine reg`（2~6s） | JSON 直写（含整段删除） |
| `WineRegistry.ensureModernLook` | 生成 modern-ui.reg + regedit /s | JSON 直写（modern-ui.json 留档） |
| `WineRegistry.purgeAppDefaultsDllOverrides` | 生成删除语义 .reg + regedit /S | JSON 值删除直删 |
| `WineLibrary.ensureApplied` | library.reg + regedit /s | JSON 直写（含 HKLM 三件套） |
| `WineLocaleSupport`（CJK 字体/用户字体注册） | 2×regedit /s | JSON 直写 |
| `GuanliSupport.AppDefaults.applyDllOverrides` | appdefaults.reg + regedit /s | JSON 直写（appdefaults.json 留档） |
| `WineRegistry.bootstrapOptPrefix` | 3×regedit + 2×wineserver 盲拉 | `/opt/prefix/*.json` 直写 + 存量 .reg **三合一**单次 regedit + wineserver 按需收尾 |

生态包/用户资产可直接带 `prefix/*.json`（registry JSON）免 regedit 打入。

## 3. bionic 调用性能（WinFusion 对照修复）

执行链本身已是直接 ProcessBuilder argv + env 白名单（无 sh 包装，与 WinFusion 同模型）；本轮消除每次启动的重复工作：

- `WineRuntime.resolve` 结果缓存（旧版一次启动 resolve×3，每次重读 container.conf 全文 + ELF 头 + box64 三候选探测；wine 安装/删除/换默认自动失效）
- conf **单遍读**：probeLine 诊断 + source 共用同一份快照（旧版 mergedConfMap 算两遍）；详见 §4（双源 mtime 合并整层移除）
- `ensureSyslibPassthrough`：系统库符号链接"指向一致跳过"（旧版每次启动 delete+重建 5 个链接）
- `GuanliSupport.scanOpt` 10s TTL 缓存（旧版一次启动扫 7 个 /opt 子目录 + UI 进 tab 再扫）
- `GuanliSupport.syncPathConfVkIcd`：内容无变化跳过重写（含 App 内部镜像）
- `SessionLogSink`：缓冲文件写（旧版**每行** open/close 日志文件，chatty stderr 上千次）；会话收尾统一 close
- tabtip 扫杀线程 3s→10s（/proc 全量扫描的持续负载）
- `loaderSmokeTest` 跨重启持久标记（wine 主程序 mtime 键，免每次 App 重启重拉 `wine --version`）
- 上述 §2 的注册表改造：每次前缀构建链少拉起约 5~10 个 wine 客户端进程（每个 1~3s）
- `WinePatchDetector`/`WineLayoutRepair` 维持原幂等语义不变（安全路径不动）

## 4. 去 /opt/conf 依赖（App 内部唯一权威）

- `ApkConfStore.mergedConfMap / mergedLocale`：**只读 App 内部 linbox-conf/**（旧版每次启动 optRoot 五候选探测 + 双源逐文件 mtime 比对 + 双份全读）。终端侧 /opt 生态改值仍生效（写透 syncOut 恒镜像 + 首装一次性导入），但启动链零 /opt 探测。
- `probeLine` 诊断行不再触发第二遍全量读。
- UI 文案同步更新（生态配置页 / DY 页提示改为 App 内部权威表述）。

## 5. 文件管理器右键 / 长按菜单

**新增**：`apps/filemanager/FileOps.kt`（剪切/复制/粘贴/重命名/删除/解压/压缩 ZIP/属性/新建 + 全局剪贴板）+ `apps/filemanager/FileContextMenu.kt`（Win7 视觉菜单 + 真鼠标右键 + 触屏长按双通道手势）。

- **真鼠标右键**（蓝牙/OTG 鼠标副键，精确到按下位置）与**长按出菜单**（触屏）；
- 菜单项：打开 / 剪切 / 复制 / 粘贴（文件夹）/ 重命名 / 删除 / **解压到此处**（zip / tar / tar.gz / tar.xz / tar.bz2 / 7z，防路径穿越）/ **添加到压缩文件（.zip）** / 属性（类型/大小/项数/修改时间/只读）；
- 空白区右键：新建文件夹 / 新建文本文档 / 粘贴 / 刷新；
- 重命名/属性/删除为 Win7 风格居中卡片对话框；重名自动「 - 副本 N」；操作完成自动刷新。

## 7. Win7 主题 UI 重制（按截图）

- **开始菜单**（`StartMenuWin7.kt`，Win7 主题自动路由）：经典**双栏**——左栏白底程序列表 + 「所有程序 ▸」（含手机应用）；右栏玻璃蓝面板：用户头像+用户名（点击→桌面设置）+ 文档/图片/音乐/计算机/控制面板/默认程序/帮助和支持链接；底栏「搜索程序和文件」+「关机 ▸」（锁定/切换用户/关闭所有窗口）。对照 win7simu 截图布局。
- **锁屏/登录界面**（`LockScreenLayer.kt` Win7LockScreen）：亮蓝壁纸（轻遮罩）+ 中央用户头像玻璃相框（点击登录）+ 用户名 + 「切换用户」玻璃按钮（头像轮换，win7simu 同款演示语义）+ 底部 Windows 四色徽标 + 右下角红色电源按钮（径向渐变）。PIN 面板/上滑解锁/返回键拦截保留。
- **窗口 Aero**（`WindowChrome.kt`）：Win7 主题标题栏玻璃渐变（顶部高光→浅蓝→过渡）+ 资源管理器式按钮（玻璃渐变底 + 高光描边，关闭键红调）。
- **缩放**：以上全部 dp/sp，在全局 UI 缩放（MainActivity LocalDensity 覆盖，0.6 基数）下整体生效——含锁屏界面。
